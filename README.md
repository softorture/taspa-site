# Taspa Studio site

One-page site of Taspa (EN and RU), an AI ad studio in Almaty. Static HTML, CSS and JS, no build step.

- Live: https://softorture.github.io/taspa-site/
- EN at `/`, RU at `/ru/` (both v4: same cases, assets and `js/main.js`; RU texts are written for the Kazakhstan and CIS market, prices in tenge with dollars)
- Works live in `assets/video` and `assets/photo`; a new case is one `<li class="case">` block in `index.html` and one in `ru/index.html` (paths with `../`)
- Forms have no backend: the free sample and the request wizard open an email or Telegram with the text filled in

All creators are AI-generated adults. Brands in the portfolio are fictional.
