# Taspa Studio site

One-page EN site of Taspa, an AI ad studio in Almaty. Static HTML, CSS and JS, no build step.

- Live: https://softorture.github.io/taspa-site/
- EN at `/`, RU (v3, to be updated) at `/ru/`
- Works live in `assets/video` and `assets/photo`; a new case is one `<li class="case">` block in `index.html`
- Forms have no backend: the free sample and the request wizard open an email or Telegram with the text filled in

All creators are AI-generated adults. Brands in the portfolio are fictional.
